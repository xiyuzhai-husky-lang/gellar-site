One-shot publication between two warps of one block, lane to lane, through a release/acquire flag and no __syncthreads: the primitive of warp specialisation. Each lane of warp 0 writes its cell of data and then sets its flag with a cuda::atomic_ref store at block scope and release order; the same lane of warp 1 spins on the flag with acquire loads and, once it sees it set, copies the cell to out. The lockstep model cannot run this kernel (a thread reads a flag another thread sets inside the one phase), so the contract is about the PTX machine: the acquire load that ends the spin reads the release store, which synchronizes the two lanes, and the Causality axiom then makes the consumer's load of data read the producer's store.note

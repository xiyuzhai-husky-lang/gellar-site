gellar

infrastructure for verifying AI infrastructure: CUDA kernels proved correct in Lean against the PTX memory consistency model · all kernels

Foundation

The PTX ISA memory consistency model (chapter 8), transcribed axiom by axiom and checked against the litmus corpus against Dartagnan's verdicts. Every contract is a theorem about every execution this model admits; the lockstep model and the interleaving machine are proved abstractions of it.

Coverage

CUDA: __global__ kernels with int/float scalars and arrays, __shared__ arrays, 1-D and 2-D launches, threadIdx/blockIdx/blockDim/gridDim, integer and float arithmetic, if/for/while, __syncthreads(), atomicAdd on int and float, __shfl_down_sync, cuda::atomic_ref loads and stores with memory_order and thread_scope.

PTX: ld/st weak, relaxed, acquire, release at cta/gpu/sys scope, red/atom, bar.sync, shfl.sync, fence.sc; morally strong operations, base causality order, observation order, coherence; the axioms Coherence, Fence-SC, Atomicity, No-Thin-Air, SC-per-location, Causality; data races as the ISA defines them.

Not covered: arbitrary CUDA, floating-point rounding error, termination of spins, Iris rules for barriers and shuffles.

Specs

A contract block beside the kernel, outside the CUDA source; the same text is the Lean proposition and the card below. Clauses: requires, ensures t when lo ≤ i < hi | otherwise, unchanged a, old(a[i]), sum k < n, e, launch 2D, physical. Meaning: under the requires, every completed race-free execution the PTX model admits satisfies the ensures, and such an execution exists. The proof is theorem k_contract : k.contract.

1__global__ void matmul_tiled(int* C, int* A, int* B, int n) {
2 __shared__ int As[256];
3 __shared__ int Bs[256];
4 int tx = threadIdx.x;
5 int ty = threadIdx.y;
6 int row = blockIdx.y * 16 + ty;
7 int col = blockIdx.x * 16 + tx;
8 int s = 0;
9 for (int k0 = 0; k0 < n; k0 += 16) {
10 As[ty * 16 + tx] = A[row * n + (k0 + tx)];
11 Bs[ty * 16 + tx] = B[(k0 + ty) * n + col];
12 __syncthreads();
13 for (int k = 0; k < 16; k++) s += As[ty * 16 + k] * Bs[k * 16 + tx];
14 __syncthreads();
15 }
16 C[row * n + col] = s;
17}

/-- Tiled matrix multiply, `C ← A·B` for square `n × n` matrices with `n` a multiple of 16: a
`16 × 16` block computes one tile of `C`, walking the `n / 16` tiles of its row of `A` and its
column of `B` through shared memory, with one barrier after loading a pair of tiles and one
after using them. The indices, every product and every partial sum of a row by a column
are computed in `int` and must fit. -/

  launch 2D
  requires blockDim.x = 16
  requires blockDim.y = 16
  requires gridDim.y = gridDim.x
  requires n = gridDim.x * 16
  requires n * n ≤ 2^31
  requires int32 (A[i * n + k] * B[k * n + j])             when 0 ≤ i < n, 0 ≤ j < n, 0 ≤ k < n
  requires int32 (sum k < K, A[i * n + k] * B[k * n + j])  when 0 ≤ i < n, 0 ≤ j < n, 0 ≤ K < n + 1
  ensures  C[i * n + j] = sum k < n, A[i * n + k] * B[k * n + j]  when 0 ≤ i < n, 0 ≤ j < n
  ensures  ∀ (c : Int), (c < 0 ∨ n * n ≤ c) → C[c] = old(C[c])
  unchanged A
  unchanged B
dot shared-memory reduction across barriers, then atomicAdd across blocks
1__global__ void dot(int* out, int* x, int* y, int n) {
2 __shared__ int s[256];
3 int tid = threadIdx.x;
4 int i = blockIdx.x * blockDim.x + tid;
5 if (i < n) s[tid] = x[i] * y[i]; else s[tid] = 0;
6 __syncthreads();
7 for (int d = blockDim.x / 2; d > 0; d /= 2) {
8 if (tid < d) s[tid] += s[tid + d];
9 __syncthreads();
10 }
11 if (tid == 0) atomicAdd(&out[0], s[0]);
12}

/-- Dot product in one pass: each block multiplies its `blockDim` pairs, reduces them in shared
memory, and adds its partial sum to `out[0]` with `atomicAdd`, so the blocks' contributions
land in any order. Products of at most 24 bits keep every block's partial sums in `int`; the
atomic adds wrap around, so the final sum must fit too. -/
contract dot (out : int*) (x : int*) (y : int*) (n : int) where
  requires blockDim ≤ 256
  requires ∃ p : Nat, blockDim = 2 ^ p
  requires n ≤ gridDim * blockDim
  requires gridDim * blockDim ≤ 2^31
  requires -2^23 ≤ x[i] * y[i] ∧ x[i] * y[i] < 2^23  when 0 ≤ i < n
  requires int32 (out[0] + sum i < n, x[i] * y[i])
  ensures  out[0] = old(out[0]) + sum i < n, x[i] * y[i]
  ensures  ∀ (i : Int), i ≠ 0 → out[i] = old(out[i])
  unchanged x
  unchanged y
publish two warps communicate through a release/acquire flag, no barrier; proved from the PTX axioms
1__global__ void publish(int* out, int* data, int* flag, int* src) {
2 int lane = threadIdx.x % 32;
3 if (threadIdx.x < 32) {
4 data[lane] = src[lane];
5 cuda::atomic_ref<int, cuda::thread_scope_block> f(flag[lane]);
6 f.store(1, cuda::memory_order_release);
7 } else {
8 cuda::atomic_ref<int, cuda::thread_scope_block> f(flag[lane]);
9 while (f.load(cuda::memory_order_acquire) == 0) {}
10 out[lane] = data[lane];
11 }
12}

/-- One-shot publication between two warps of one block, lane to lane, through a release/acquire
flag and no `__syncthreads`: the primitive of warp specialisation. Each lane of warp 0 writes
its cell of `data` and then sets its flag with a `cuda::atomic_ref` store at block scope and
release order; the same lane of warp 1 spins on the flag with acquire loads and, once it sees
it set, copies the cell to `out`. The lockstep model cannot run this kernel (a thread reads a
flag another thread sets inside the one phase), so the contract is about the PTX machine: the
acquire load that ends the spin reads the release store, which synchronizes the two lanes, and
the Causality axiom then makes the consumer's load of `data` read the producer's store. -/
contract publish (out : int*) (data : int*) (flag : int*) (src : int*) where
  physical
  requires gridDim = 1
  requires blockDim = 64
  requires flag[i] = 0  when 0 ≤ i < 32
  ensures  out[i] = src[i]  when 0 ≤ i < 32
  ensures  out[i] = old(out[i])  otherwise
  ensures  data[i] = src[i]  when 0 ≤ i < 32
  ensures  data[i] = old(data[i])  otherwise
  ensures  flag[i] = 1  when 0 ≤ i < 32
  ensures  flag[i] = old(flag[i])  otherwise
  unchanged src

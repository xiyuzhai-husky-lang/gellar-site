gellar

the GPU as a physical machine, in Lean · kernel contracts

The ground truth is the PTX ISA memory consistency model (chapter 8), transcribed axiom by axiom. A kernel's contract is a theorem about every execution that model admits. Two abstractions prove them, each with its own justification theorem against the machine: a lockstep model for barrier-synchronized kernels, and an interleaving machine for kernels whose threads communicate, with Iris (iris-lean) on top.

Proved

Kernel.phys_of_lockstep Gellar/Machine/Exists.lean
A launch the lockstep model finds Safe and DRF: every consistent race-free PTX execution ends in the memory Kernel.run computes, and one exists.
Assumes: well-typed inputs; body in the lockstep fragment.
publish_contract Specs/Publish.lean
Release/acquire publication between two warps, from the PTX axioms: the acquire load that ends the spin reads the release store; Causality leaves the consumer's load of data only the producer's write.
Assumes: the contract's requires.
behaviour_of_run Gellar/SC/Behaviour.lean
A completed run of the interleaving machine whose events are race free is a behaviour of the launch on the PTX machine, same final memory.
Assumes: race-free events; arrays accessed with their kind.
run_of_exec Gellar/SC/Replay.lean
A consistent PTX execution is replayed by a completed run of the interleaving machine, same traces, same final memory.
Assumes: strict race freedom; one barrier sequence per block; no shuffles; kinds.
publish_run Specs/PublishIris.lean
publish in Iris on the interleaving machine: every completed run leaves out and data equal to src, the flags set, every other cell unchanged.
Assumes: int32 inputs; flags 0 at start.
phys_of_poolPost Gellar/SC/Phys.lean
What Iris proves of every terminated thread pool is a physical contract of the launch.
Assumes: the hypotheses of run_of_exec; one race-free completed run.

These and every contract below use only propext, Classical.choice and Quot.sound; no sorry anywhere.

Not proved

  • run_of_exec excludes shuffles: the ISA makes shfl.sync a rendezvous without memory ordering, so the model admits a lane receiving before another lane has reached the shuffle.
  • run_of_exec needs strict race freedom, which release/acquire does not give (store buffering is allowed). The interleaving machine is exact for barrier-synchronized kernels; for a spinning kernel like publish it speaks about the sequentially consistent runs, and the direct proof carries the PTX claim. Next: a view-based machine.
  • No Iris rules for barriers and shuffles yet; the kernels using them are proved in the lockstep model.
  • Floats are (machine value, exact value) pairs; rounding error is in no contract.
  • Liveness: nothing says a spin terminates.

The indices, every product and every partial sum of a row by a column are computed in int and must fit. ✓ proved

    publish kernels/publish.cuOne-shot publication between two warps of one block, lane to lane, through a release/acquire flag and no __syncthreads: the primitive of warp specialisation. Each lane of warp 0 writes its cell of data and then sets its flag with a cuda::atomic_ref store at block scope and release order; the same lane of warp 1 spins on the flag with acquire loads and, once it sees it set, copies the cell to out. The lockstep model cannot run this kernel (a thread reads a flag another thread sets inside the one phase), so the contract is about the PTX machine: the acquire load that ends the spin reads the release store, which synchronizes the two lanes, and the Causality axiom then makes the consumer's load of data read the producer's store. ✓ proved

    scale kernels/scale.cuScales the first n cells of x by a in place. The products must fit in an int. ✓ proved
    scan kernels/scan.cuInclusive prefix sum of each block's blockDim cells (Hillis–Steele in shared memory): out[i] is the sum of the block's cells up to and including i. Every partial sum is a sum of at most 256 cells, so cells of at most 24 bits keep the sums in int. ✓ proved

    select kernels/select.cuout[i] is a[i] where mask[i] is set and b[i] elsewhere, on the first n cells. ✓ proved
    shift kernels/shift.cuCopies the first n cells of src to out, shifted by off. The shifted indices must fit in an int. ✓ proved
    smooth_f kernels/smooth_f.cuA three-point smoothing of x into out: every interior cell becomes half itself plus a quarter of each neighbour, exactly. The constants are the float literals 0.5f, 0.25f, whose exact values are what the clause says. The guard computes n - 1 in int, so n must not be INT_MIN. ✓ proved
    stencil kernels/stencil.cuA three-point stencil, one block at a time through shared memory: every interior cell of a block becomes the sum of itself and its two neighbours; the two edge cells of each block are left alone. The sum is formed left to right in int, so both partial sums must fit. ✓ proved
    sum_f kernels/sum_f.cuAdds the first n cells of x into out[0] with atomicAdd, in whatever order the hardware runs the threads. The exact value of out[0] is the exact sum; its rounded bits depend on the order and are not constrained. ✓ proved
    transpose kernels/transpose.cuTiled transpose: each 16 × 16 block stages its tile of the rows × cols matrix src in shared memory, synchronises, and writes the tile transposed into the cols × rows matrix out, so that both the reads and the writes of global memory run along rows. ✓ proved
    transpose_naive kernels/transpose_naive.cuTransposes the rows × cols row-major matrix src into the cols × rows matrix out, one element per thread of a two-dimensional launch. The coordinates and the linear indices are computed in int. ✓ proved
    vadd kernels/vadd.cuc ← a + b on the first n cells. The sums must fit in an int. ✓ proved
    warp_sum kernels/warp_sum.cuWarp reduction: one warp per block, each lane loads one cell (zero past n), and five __shfl_down_sync rounds fold the warp's values into lane 0, which writes the block's sum. No shared memory and no barrier: the exchange is between registers. Every lane's running sum is a sum of at most 32 loaded values (a lane past the warp's edge adds its own value again), so loaded values of at most 26 bits keep the sums in int. ✓ proved
